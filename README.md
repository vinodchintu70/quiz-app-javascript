# Quiz App

A simple Quiz App built using HTML, CSS, and JavaScript.

## Features

- 8 JavaScript questions
- Multiple-choice answers
- Correct/Wrong answer checking
- Score calculation
- Next question functionality
- Prevents multiple answers for the same question
- Final score display

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Practiced

- Arrays and objects
- DOM manipulation
- Event listeners
- forEach()
- Conditional statements
- Managing application state
